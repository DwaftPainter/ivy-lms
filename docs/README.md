## Project Overview

IVY LMS is a full-featured Learning Management System designed for IELTS preparation, built with:

- **Next.js 16** with App Router
- **React 19** and TypeScript
- **PostgreSQL** with Prisma ORM
- **Tailwind CSS** and shadcn/ui
- **Zustand** for state management

### Key Features

- **Multi-role system**: Admin, Teacher, Student
- **IELTS Skills**: Listening, Reading, Writing, Speaking
- **AI Grading**: Automated essay evaluation with Ollama
- **Assignment Management**: Create, submit, and grade
- **Real-time Notifications**: In-app notification system
- **OAuth Integration**: Google login via Auth0
